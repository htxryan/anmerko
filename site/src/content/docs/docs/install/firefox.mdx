Use Firefox 142 or later.

## Install from Firefox Add-ons

1. Open [anmerko on Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/anmerko/).
2. Select **Add to Firefox** and accept the installation prompt.
3. Activate anmerko from the Extensions menu on a regular website. You can pin it to the toolbar.

Firefox Add-ons installations update automatically.

## Install a signed file

<Download browser="firefox" />

1. Open `about:addons` and select **Extensions**.
2. Open the gear menu and choose **Install Add-on From File…**.
3. Select the downloaded `.xpi` and accept the installation prompt.

Install only the signed `.xpi`; source and unsigned archives are not installers. To update a manual installation, install the newer signed XPI in the same Firefox profile without removing the extension first.

Use Firefox 142 or later.

## Install from Firefox Add-ons

1. In Firefox for Android, open [anmerko on Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/anmerko/).
2. Select **Add to Firefox** and accept the installation prompt.
3. Open a regular website and choose anmerko from **Extensions**.

Firefox Add-ons installations update automatically.

## Install a signed file

Manual file installation requires Android 10 or later.

<Download browser="firefox" />

1. Open **Settings → About Firefox** and tap the Firefox logo five times.
2. Return to Settings and choose **Install extension from file**.
3. Select the signed `.xpi` and accept the installation prompt.

To update a manual installation, install the newer signed XPI over the existing extension in the same Firefox profile.

title: Orion on iPhone

---

Install anmerko in [Orion Browser by Kagi](https://apps.apple.com/app/orion-browser-by-kagi/id1484498200) from a locally delivered package.

## Prepare Orion

1. Install Orion from the App Store and open it once.
2. In Orion, open **Settings → Extensions**.
3. Enable Chrome extension support. Depending on your Orion version, this may appear as **Chrome Extensions** or as a Chrome extensions toggle under **Extensions**.

## Save the extension folder

1. Send `anmerko-<version>-orion.zip` to your iPhone with AirDrop or iCloud Drive, then save it in the Files app.
2. In Files, tap the ZIP to unzip it. Files creates a folder named after the archive.
3. Rename the unzipped folder to `anmerko` so it has the same name when you update it later.
4. In Files, open **Browse → On My iPhone → Orion → Extensions**. Use the Orion location created by the app. If needed, create an `Extensions` folder inside that Orion location.
5. Move the entire `anmerko` folder into **Orion/Extensions**. Keep the files together; `manifest.json` must remain at the top level of that folder.

## Install anmerko

1. Return to Orion and open **… → Extensions**.
2. Select **+**, then **Install from File**.
3. Choose the anmerko folder containing `manifest.json` in **On My iPhone/Orion/Extensions**.
4. Confirm that anmerko is enabled in Orion's extension list.

## Add comments

1. Open a regular `http://` or `https://` page in Orion.
2. Open Orion's extension menu and choose **anmerko**. If Orion asks for website access, allow it for the page you want to annotate.
3. Select **Annotate This Page**.
4. Add [inline comments](/docs/usage/inline-comments/), [screenshot comments](/docs/usage/screenshot-comments/), or [global comments](/docs/usage/global-comments/).
5. [Copy the prompt or export Markdown and images](/docs/send-to-your-agent/).

## Update manually

Before updating, export feedback you need to keep. Unzip the newer Orion package, name its folder `anmerko`, and replace the existing folder at **On My iPhone/Orion/Extensions/anmerko**. Then use **Install from File** again and select that folder. Keep a single anmerko installation enabled.

## Troubleshooting

### The folder is missing from the picker

In Files, confirm the archive is unzipped and the whole resulting folder is under **On My iPhone/Orion/Extensions**. Open the folder and check that `manifest.json` is directly inside it at the top level.

If the **Orion** location is missing, open Orion and enable extension support, then return to **Browse → On My iPhone** in Files. Use the app's Orion location; a separate folder named Orion in iCloud Drive or Downloads is a different location.

### Annotate This Page does nothing

Open a regular `http://` or `https://` page, reload it, and try again.

### The extension is unavailable on a website

Confirm anmerko is enabled under **Settings → Extensions**. In the website menu, turn off Orion's **Compatibility Mode** for that site, reload the page, and open anmerko again.

anmerko targets **Chrome, Edge, and Firefox on desktop**, and **Edge and Firefox for Android on mobile**. Chrome, Edge, and Firefox 0.5.5 are publicly listed for their supported platforms. Chrome on mobile and all browsers on iPhone and iPad are not supported.

## Install from a browser store

| Browser | Store | Guide |
| --- | --- | --- |
| Chrome on desktop | [Chrome Web Store](https://chromewebstore.google.com/detail/anmerko/oligkkknbmklalfnkipmheifammnpgpo) | [Install in Chrome](/docs/install/chrome/) |
| Edge on desktop | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/anmerko/bfhobiphegcekelfokpcpeepoakkgcka) | [Install in Edge](/docs/install/edge/) |
| Firefox on desktop | [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/anmerko/) | [Install in Firefox](/docs/install/firefox/) |
| Edge for Android | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/anmerko/bfhobiphegcekelfokpcpeepoakkgcka) | [Install on Android](/docs/install/edge/#android) |
| Firefox for Android | [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/anmerko/) | [Install on Android](/docs/install/firefox/#android) |

Manual downloads remain available if you cannot or prefer not to use a browser store. Each download notes the name it displays after installation.

| Browser | File to download | Instructions |
| --- | --- | --- |
| Chrome on desktop | Chrome ZIP linked above | [Install in Chrome](/docs/install/chrome/) |
| Edge on desktop | Edge ZIP linked above | [Install in Edge](/docs/install/edge/) |
| Firefox on desktop | Signed Firefox XPI linked above | [Install in Firefox](/docs/install/firefox/) |
| Edge for Android | Microsoft Edge Add-ons; desktop ZIPs do not install on Android | [Install on Android](/docs/install/edge/#android) |
| Firefox for Android | Signed Firefox XPI linked above | [Install on Android](/docs/install/firefox/#android) |

Files labeled `firefox-source` or `firefox-unsigned` are for development or review, not normal installation. Firefox needs a Mozilla-signed `.xpi`; renaming a ZIP does not make it installable.

Manual installations need manual updates. Follow your browser's guide below and keep the same browser profile. Feedback does not sync between browsers or devices.

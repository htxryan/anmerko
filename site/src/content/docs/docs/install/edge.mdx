## Install from Microsoft Edge Add-ons

1. Open [anmerko on Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/anmerko/bfhobiphegcekelfokpcpeepoakkgcka).
2. Select **Get**, then **Add extension**.
3. Show anmerko in the Extensions toolbar and activate it on a regular website.

Store installations update automatically.

## Install manually

<Download browser="edge" />

1. Extract the ZIP into a permanent folder.
2. Open `edge://extensions` and turn on **Developer mode**.
3. Select **Load unpacked** and choose the extracted folder containing `manifest.json`.
4. Show anmerko in the toolbar, refresh the website where you want to use it, and activate the extension.

To update, replace the files in the same folder, select **Reload** on the extension card, and refresh open websites. Export feedback before removing the extension, changing its folder, or changing browser profiles.

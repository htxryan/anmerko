---
title: Edge Android
description: Install anmerko in Microsoft Edge for Android.
---

1. In Edge for Android, open [anmerko on Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/anmerko/bfhobiphegcekelfokpcpeepoakkgcka).
2. Follow the installation prompt.
3. Open a regular website and activate anmerko from **Extensions**.

Microsoft Edge Add-ons manages updates.

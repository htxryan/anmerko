Use Chrome 142 or later.

## Install from the Chrome Web Store

1. Open [anmerko in the Chrome Web Store](https://chromewebstore.google.com/detail/anmerko/oligkkknbmklalfnkipmheifammnpgpo).
2. Select **Add to Chrome**, then **Add extension**.
3. Pin anmerko from the Extensions menu and activate it on a regular website.

Store installations update automatically.

## Install manually

<Download browser="chrome" />

1. Extract the ZIP into a permanent folder.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Select **Load unpacked** and choose the extracted folder containing `manifest.json`.
4. Pin anmerko, refresh the website where you want to use it, and activate the extension.

To update, replace the files in the same folder, select **Reload** on the extension card, and refresh open websites. Export feedback before removing the extension, changing its folder, or changing browser profiles.
